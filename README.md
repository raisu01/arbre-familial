# Arbre familial

Application web gratuite pour créer un arbre généalogique, sur un seul écran, sans inscription.

**En ligne : https://raisu01.github.io/arbre-familial/**

- Clique sur une personne pour ajouter père, mère, frère, sœur, conjoint(e), fils ou fille : la fiche se place et se relie toute seule.
- Glisser une fiche pour l'ajuster, « Ranger » pour tout remettre en place, zoom à la molette ou au pincement.
- Sauvegarde automatique dans le navigateur (localStorage), Annuler / Rétablir.
- Export PNG, PDF (via l'impression) et JSON, import JSON.

Un seul fichier `index.html`, sans dépendance ni build. Pour l'utiliser en local, ouvre simplement `index.html` dans un navigateur.
